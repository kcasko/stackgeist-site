# Site review, November 6, 2026

Reviewed https://stackgeist.dev and the local production build on master after
affiliate-link commit `7ad7a22`. The fixes below are local working-tree changes.
They have not been committed, pushed, or deployed in this review.

## Confirmed defects fixed

1. **Consent dismissal moved readers to the footer.** On a fresh mobile visit,
   clicking Decline focused the footer settings control and scrolled from the
   top to roughly 7,751 pixels down. The panel now remembers its opener. On a
   first visit it returns focus to the main content without scrolling; reopening
   from the footer still returns focus to that button. Browser checks verified
   both cases.
2. **Step numbers had low contrast in both themes.** The general article
   paragraph rule overrode the badge text color. Contrast was approximately
   2.51:1 in light mode and 2.12:1 in dark mode. The badge selector now takes
   precedence: white text on the dark red light-theme badge and near-black text
   on the lighter dark-theme badge. Checked computed styles and visual output.
3. **Two Cloudflare analytics scripts loaded with different tokens.** A manual
   snippet in SeoHead duplicated Cloudflare's injected script and generated
   cross-origin errors. Removed the manual snippet; Cloudflare delivery still
   supplies analytics. An isolated browser test intercepted the live homepage
   response and removed only the manual script: one beacon remained and no
   console errors were recorded in that test. The deployed fix still needs
   verification after release. No Cloudflare account configuration was changed.
4. **Homepage overflow on 320-pixel screens.** The department grid kept its
   twelve desktop tracks and eleven gaps even when the sections stacked. This
   made the page 48 pixels too wide. At the stacking breakpoint the grid now
   explicitly has one shrinking column. No overflow remained at 320, 390, 768,
   or 1440 pixels in either theme.
